# 🔐 Vulnerability Assessment & Risk Prioritization
### Cyber Security Internship – Task 15

## 📌 Objective
To perform vulnerability assessment on target systems using Nessus/OpenVAS and identify, analyze, and prioritize security risks based on CVSS severity.

---

## 🛠 Tools Used
- Nessus Essentials
- Kali Linux
- Nmap (for host discovery)
- CVE Database
- CVSS Scoring

---

## 🎯 Scope
Target System: Local test machine / lab environment  
IP Range: 192.168.x.x  

---

## 🔍 Methodology

### Step 1 – Scope Definition
Identified systems to scan and defined boundaries.

### Step 2 – Scan Configuration
Configured vulnerability scanner:
- Basic Network Scan
- Medium + High severity checks
- Service detection enabled

### Step 3 – Vulnerability Scan
Executed scan and monitored progress.

### Step 4 – Analysis
- Reviewed vulnerabilities
- Mapped CVE IDs
- Checked CVSS scores
- Classified severity

### Step 5 – Risk Prioritization
Categorized:
- Critical
- High
- Medium
- Low

### Step 6 – Remediation
Suggested patches and mitigation strategies.
